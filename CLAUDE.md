# SlideSmith

Web app that makes a teacher's daily slide decks. Teachers upload their own .pptx decks as "styles";
for each lesson they type notes per page (plus optional images) and get a .pptx back in their style.
Full history and decisions: `docs/HANDOFF.md`.

## Core design rule (do not break)
The AI writes **text only**. Style comes from **cloning the teacher's own sample slides** inside their
file (python-pptx), replacing text/pictures, then deleting the samples. Never generate layouts, colours
or fonts with the model, and never let the model touch PowerPoint XML.

## Layout
- `backend/app/` FastAPI + python-pptx + SQLite (stdlib) + Pillow + Anthropic SDK + PyMuPDF
  - `main.py` routes · `config.py` env/paths · `db.py` sqlite · `schemas.py` Pydantic models
  - `pptx_analysis.py` classify sample slides (title/content/image/section), find shapes
  - `generator.py` clone best sample, fill text/pictures, fit text, build deck
  - `ai.py` Claude forced tool call `submit_slides` → JSON; mock mode when no API key
  - `previews.py` pptx → pdf (LibreOffice, one at a time) → jpg
- `backend/tests/` pytest; fixtures generated by `tests/make_fixtures.py`
- `frontend/` Angular 21: standalone components, signals, zoneless, `@if/@for/@let`, plain CSS tokens,
  lazy routes (`pages/styles`, `pages/create`). Dev proxy `/api` and `/files` → :8000.

## Run
```bash
# backend (from backend/)
source .venv/bin/activate && uvicorn app.main:app --reload --port 8000
# frontend (from frontend/) — use start:cloud inside Codespaces
npm start            # or: npm run start:cloud
```
Health: `GET /api/health` → `ai_enabled`, `model`, `previews_enabled`.
No `ANTHROPIC_API_KEY` in `backend/.env` = demo (mock) mode.

## Before saying a task is done
1. `cd backend && .venv/bin/python -m pytest -q` passes
2. `cd frontend && npm run build` succeeds
3. Tell the user the manual browser steps that check the change

## Rules
- Never commit `.env`, `backend/storage/`, real teacher decks, or anything with pupil data.
- New behaviour gets a test; reproduce pptx bugs with a fixture in `make_fixtures.py`, not a real deck.
- Angular: keep components standalone, state in signals (zoneless: no reliance on zone.js).
- One feature per branch (`feature/...`, `fix/...`), merged through a PR that closes its issue.

## Gotchas
- python-pptx can't write WebP: images are converted on upload.
- Strip the PowerPoint "sections" extension after deleting samples, or PowerPoint offers repair.
- LibreOffice must run one conversion at a time with its own profile dir (lock in `previews.py`).
- `npm install` "edgesOut" error → `--legacy-peer-deps`.
- Text fitting is estimated, not measured; min title 24pt, body 14pt.
